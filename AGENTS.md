# AGENTS.md

## Cursor Cloud specific instructions

Dotfiles + AI-coding tooling repo. Shell scripts install dotfiles and mirror
the commands + skills carried by the five plugins under `ai-coding/plugins/`
into the Cursor and Claude home locations.

Setup runs the repo's own `install.sh`. Run `make help` for details on sync and
other targets.

See `README.md` for more information, and `ai-coding/README.md` for the plugin
layout and sync scripts.
