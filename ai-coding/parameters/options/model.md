# `model` — the model the current agent runs analysis on

The model used for each critique analysis run (default: the parent
agent's model; the resolved value is restated in the report header). The
only live declaration of the "which model does the current work" concept
— distinct from `agent_model`, which assigns models to spawned workers.

- **Used by:** critique
- **Full entry:** [concerns/models.md](../concerns/models.md#artifact-specific)
