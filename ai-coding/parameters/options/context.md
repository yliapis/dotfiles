# `context` — the subject artifact an invocation operates on

The artifact the command or skill works over, supplied as data (file path,
directory, URL, inline text, or free-form description); the verb lives in
the artifact itself (`critique` analyzes it, `designer` designs it).
Aliased as `target` (designer, designer-controller) and `domain`
(ralph-design).

- **Used by:** critique, designer, designer-controller, ralph-design
