# `pattern` — preset shortcut bundling swarm defaults

Preset shortcut: `sanity` | `diversity` | `consensus` | `synthesize` |
`tournament`. Supplies defaults for `{num_agents}`, `{model_mix}`, and
`{selection_modes}` from the Pattern Catalog; user-set parameters always
override preset defaults.

- **Used by:** agent-swarm
