# `criteria` — the judgment rubric critique evaluates against

The rubric findings are evaluated against; accepts file | directory |
inline. Default: quality (clarity, correctness, completeness, robustness)
+ determinism (reproducibility, idempotency, stable outputs across runs).
Every finding must name the specific criterion it relates to.
