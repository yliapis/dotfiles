# `style` / `styles` — design dimensions biasing prompt drafting

Synonyms; a single trait name or a comma-separated list of design
dimensions to prioritize when meta-prompt drafts or refines wording and
criteria (accuracy, consistency, reliability, conciseness, simplicity,
...). Kin to `traits` but free-form: no registry, no skill files. Parsed
from `{input}` and propagated verbatim to spawned variant agents.
