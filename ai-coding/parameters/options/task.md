# `task` — the goal a spawned agent must complete

Free-text imperative describing what each spawned agent must complete
end-to-end inside its own workspace, including verification. Broadcast
verbatim to every member; agent-swarm relays it unchanged into
worktree-task.

- **Used by:** worktree-task (declared), agent-swarm (relayed, undeclared)
- **Full entry:** [concerns/intent.md](../concerns/intent.md#task)
