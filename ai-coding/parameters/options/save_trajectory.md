# `save_trajectory` — whether trajectory and learnings files are written

Whether wrap-up writes the trajectory + learnings files (to
`{trajectory_path}` / `{learnings_path}`). Default: `interactive` (prompt
at end) when `-i` is set, `false` otherwise.
