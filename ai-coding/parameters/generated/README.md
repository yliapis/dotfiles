# Parameters Generated Samples

Per-task variant explorations of `ai-coding/parameters/` design docs from an
earlier swarm experiment. Layout: `<task>/<descriptor>-<sample-index>.md`.

- `param-ontology/` — flat (1) and layered (2) ontology shapes
- `param-stages/` — staged-evaluation variant (1)
- `parameters/` — lifecycle (1) and tree (2) variants of root/input docs
- `params/` — concern (1), twonamespace (2), and type-first (3) namespace variants

The source branches were deleted after this archive was created.
