## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`install.sh` copies `home-config/` and wires `~/.shell_extras.sh` into the profile on every platform, but installs the Brewfile that provides fzf and starship only on macOS or with `BREW_BUNDLE=1`. On the default Linux path every new interactive shell then emits `command not found` from the managed snippet. The `wt` block four lines below shows the intended guard pattern.

### Evidence (main @ 225cbf2, 2026-09-08)

- `home-config/.shell_extras.sh:34` `source <(fzf --"$_dotfiles_shell")` and `:36` `eval "$(starship init "$_dotfiles_shell")"` run unconditionally; `:38-40` guard `wt` with `command -v`.
- `install.sh:276-282` gates the Brewfile; `install.sh:320-321` copy and wire the extras regardless.
- `Brewfile:22` and `:64` are the only sources of starship and fzf.

Fable 2026-07-12 (major), Composer 2026-07-12 (major, 2/10, live-verified), Kimi 2026-07-26 (major).

### Scope
