# Docs

Repository documentation.

## Layout

| Path | Purpose |
|---|---|
| `pr-template.md` | Body for agent-opened PRs (`gh pr create`). Referenced from [AGENTS.md](../AGENTS.md). |

Critique and review reports are not kept in this tree: their findings go
into backlog tickets and the report is removed. Earlier reports remain in
git history.

Work items live in the repo-root [Backlog.md](https://github.com/MrLesk/Backlog.md)
project, not under `docs/`. One Markdown task per work item sits in
`backlog/tasks/`, and `backlog task list` or `backlog board` replaces the
`WORKLIST.md` projection the previous `docs/tickets/<source-slug>/` sets carried.
