# Docs

Repository documentation and agent-generated analysis artifacts.

## Layout

| Path | Purpose |
|---|---|
| `reports/` | Committed critique, review, and analysis reports. |
| `tickets/<source-slug>/` | Committed `ticket-operations` sets: one Markdown ticket per work item plus the managed `WORKLIST.md` projection. Ticket frontmatter is lifecycle authority; `WORKLIST.md` is only its projection. |
